# Install on Microsoft Edge

Use the unpacked extension source in `../extension/` for a local developer install.

## Steps

1. Open Microsoft Edge.
2. Visit `edge://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the `connectors/webui-connector/extension/` folder.

## Important

- Do not point Edge at the ZIP file. Edge needs the unpacked folder.
- Keep the folder in place after loading it or Edge will disable the extension.
- Default hotkeys and behavior notes are documented in this connector's overview and the extension UI.
