# How to Install the ChatGPT DOM Adapter Extension on Microsoft Edge

This is the upstream install guidance preserved with the imported connector.

## Short version

1. Open `edge://extensions`.
2. Enable Developer Mode.
3. Click **Load unpacked**.
4. Select `connectors/webui-connector/extension/`.

## Important notes

- Edge cannot load the ZIP directly.
- The unpacked folder must remain in place.
- If nothing appears to happen, check the console on `chatgpt.com`.
